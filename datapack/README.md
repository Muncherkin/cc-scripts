# core_factory_chisel

A datapack that adds every Factory Blocks variant to one Rechiseled chiseling
group. With it, a Rechiseled chisel, and Rechiseled: Create's Mechanical
Chisel, can turn plain Factory Blocks (4 iron + 4 stone -> 32) into any
variant without the Chipped Mason Table, which only a player can use.

Install: copy the `core_factory_chisel` folder into the server world's
`datapacks/` folder (needs server access) and run `/reload`.

The factory can then feed a row of Mechanical Chisels (each set to one
variant) through depots on its wired network: the Chisel Bank in the design.
